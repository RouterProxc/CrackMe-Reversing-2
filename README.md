Перехожу к sub_401000;


В этой функции проверяются соответствия логина и пароля (проверка пароля напрямую зависит от логина)

Для начала длина логина должна быть не менее 3 символов

Длина пароля же должна быть равна 11

Шестой символ пароля должен быть равен 45 ( "-" по ascii )

В цикле мы вычитаем 48 ( '0' ) из каждого из первых пяти символов пароля

То есть, мы превращаем из символьного числа ( по ascii ) в int

Если мы введем "12345", то после цикла мы будем иметь те же 12345, но не в качестве символов, а в качестве полноценных цифр

Дальше идет ряд проверок зависимости одной из этих цифр от другой, тут я написал генератор от 0 до 99999 с последующей проверкой на соответствие пароля
