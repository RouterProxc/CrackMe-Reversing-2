Перехожу к sub_401000;


В этой функции проверяются соответствия логина и пароля (проверка пароля напрямую зависит от логина)

Для начала длина логина должна быть не менее 3 символов

Длина пароля же должна быть равна 11

Шестой символ пароля должен быть равен 45 ( "-" по ascii )

В цикле мы вычитаем 48 ( '0' ) из каждого из первых пяти символов пароля

То есть, мы превращаем из символьного числа ( по ascii ) в int

Если мы введем "12345", то после цикла мы будем иметь те же 12345, но не в качестве символов, а в качестве полноценных цифр

Дальше идет ряд проверок зависимости одной из этих цифр от другой, тут я написал генератор от 0 до 99999 с последующей проверкой на соответствие пароля

Как именно проверяется соответствие пароля с логином?

Идет проверка что остаток от деления первых 3 символов логина равен полноценным числам последних трех символов пароля

То есть если нам требуются "xx911", то первые 3 символа пароля должны во 2 разряде иметь 9>1>1 

Теперь можно прибавить к ним достаточно большое число с 0 во втором разряде чтобы символ этого числа можно было ввести в поле ввода

Я просто прибавил 60 и получил 69>61>61 = "E=="

С этими данными я прошел первую проверку, касаемо второй проверки все чуть сложнее

Мы берем и суммируем цифровые значения всех символов логина, умножаем сумму на константу 0xFEAD, обнуляем все байты кроме последних 5

С моими данными я получил E0313

Далее через цикл мы сверяем последние 5 цифр пароля (после тире) с полученными данными

То есть для одного из успешных решений я подобрал "E==", "99911-E0313"
